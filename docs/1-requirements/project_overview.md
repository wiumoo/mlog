# mlog(먹방로그) 프로젝트 개요

## 1. 프로젝트 소개

mlog는 사용자가 맛집을 탐색하고, 방문 후기를 게시글로 공유하며, 다른 사용자와 소통할 수 있는 맛집 추천 커뮤니티 서비스이다.

백엔드 개발 역량을 보여주기 위해 로그인, 맛집 조회, 게시글, 좋아요, 팔로우, 추천 기능을 중심으로 구현한다.

## 2. 프로젝트 목표

- Spring Boot 기반 백엔드 서비스 개발
- MySQL을 활용한 관계형 데이터 모델링
- MyBatis 기반 데이터 접근 계층 구현
- Redis를 활용한 인증 코드, 캐싱, 랭킹 처리
- Kafka를 활용한 이벤트 기반 비동기 처리
- 면접에서 설명 가능한 실전형 프로젝트 완성

## 3. 주요 사용자

- 맛집을 찾는 일반 사용자
- 맛집 후기를 공유하는 사용자
- 다른 사용자의 맛집 기록을 참고하는 사용자

## 4. 핵심 기능

- 사용자 로그인
- 맛집 조회
- 맛집 상세 정보 조회
- 게시글 작성
- 게시글 좋아요
- 사용자 팔로우
- 인기 맛집 추천
- 인기 게시글 조회
