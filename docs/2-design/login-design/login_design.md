# Login Design

## 1. 기능 개요

mlog의 로그인은 휴대폰 번호 기반 문자 인증 로그인 방식으로 구현한다.

사용자는 휴대폰 번호를 입력하고 인증번호를 요청한다. 서버는 인증번호를 생성한 뒤 Redis에 저장하고, 사용자가 입력한 인증번호와 Redis에 저장된 값을 비교하여 로그인 여부를 판단한다.

회원가입을 별도로 분리하지 않고, 인증번호 검증에 성공했을 때 해당 휴대폰 번호의 사용자가 없으면 자동으로 회원가입 처리한다.

---

## 2. 로그인 방식

### 2.1 인증번호 요청 흐름

```text
사용자 휴대폰 번호 입력
→ 서버에 인증번호 요청
→ 서버가 6자리 인증번호 생성
→ Redis에 인증번호 저장
→ 문자 발송
→ 응답 반환

사용자 휴대폰 번호 + 인증번호 입력
→ Redis에서 인증번호 조회
→ 인증번호 비교
→ 일치하면 사용자 조회
→ 사용자가 없으면 신규 사용자 생성
→ JWT 발급
→ 로그인 성공 응답
